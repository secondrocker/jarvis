# Beauty Image Rating 年龄规则清理设计

## 目标

`beauty-image-rating` 的输入图片已由上游保证为合法成年人数据。Skill 不再判断、提示或输出成年/未成年相关信息，避免重复检查和无效字段。

## 修改范围

- 将标题、描述和任务目标中的“成年女性”统一改为“女性人物”。
- 删除成年状态检查、年龄不确定处理和未成年处理规则。
- 删除 `age_gate`、年龄相关 `review_reason`、年龄扣分、年龄置信度限制及 `REVIEW` 等级规则。
- 删除执行流程和特殊媒体规则中的年龄判断步骤。
- 将 `成年可爱风` 重命名为 `可爱风`，将 `成人JK风` 重命名为 `JK风`。
- 同步更新标签表、评分表、偏好排序、示例 JSON 和输出一致性要求。

## 保留行为

- 继续只根据图片中的可见证据生成标签，不推测身份、职业、民族、国籍、性格或健康状况。
- 继续输出图片标签、构图、质量、偏好评分、综合评分和整体置信度。
- 继续在主要人物无法确定时输出 `manual_review` 和对应原因。
- 动漫、插画、AI 生成图等媒体类型仍按现有规则识别并分开排序。

## 输出变化

单图 JSON 从 `image_id` 后直接输出 `primary_subject`，不再包含 `age_gate`。所有输出字段、原因文本和标签值均不得出现成年、未成年或年龄判断信息。

## 验证

- 搜索目标文件，确认不存在 `成年`、`未成年`、`年龄`、`adult`、`minor`、`youthful` 等遗留词。
- 检查示例 JSON 可解析，评分分项与现有公式保持一致。
- 运行仓库现有的 Skill 校验或相关测试；若没有专用测试，则至少执行结构和差异检查。
