# 英语作业批改规范

## 书写规范（小学阶段首要）

- 手写体、四线格占位正确（占格、出格、大小写高度）；
- 句首字母大写、专有名词大写；句末标点正确（. / ? / !）；
- 单词之间留一个字母宽度的间距，不连写、不拆词；
- 书写不规范属于 `habit` 错因：写在 `comment` 里提示，不要因此判答案错误。

## 单词 / 拼写类

- **逐字母比对**，多字母、漏字母、颠倒字母都算错；
- 常见易错：i/e 顺序（friend, receive）、双写辅音（beginning）、
  不发音字母（knife, Wednesday）、-ing/-ed 变化规则；
- `error_detail.correct_form` 写出正确拼写，`reason` 指出错在哪个字母或哪条规则；
- 单词形式（单复数、第三人称单数、过去式、比较级）按题目要求核对，
  拼写对但形式错属于 `language`，不要与拼写错误混为一谈。

## 语法 / 句型类

按语法点逐项核对并写进 `error_type`：

| 语法点 | 检查内容 |
| --- | --- |
| 时态 | 时间状语与动词形式是否一致 |
| 主谓一致 | 第三人称单数、复数名词 |
| 冠词 | a / an / the 的选择与省略 |
| 介词 | in / on / at、固定搭配 |
| 代词 | 主格宾格、形容词性与名词性物主代词 |
| 句式 | 一般疑问句、否定句、特殊疑问句的语序 |

- 逐空判定：一空一判，填错即该空为错；句型转换漏改一处算 `partial`；
- 翻译题学生用词与参考答案不同但意思准确的**不扣分**，
  `confidence` 记 `high` 并在 `comment` 里说明"表达不同、意思正确"。

## 书面表达 / 小作文

- `answer_type=open`，按维度评档：**内容要点是否齐全、语言（语法/词汇/拼写）、
  连贯性（连接词、语序）、书写**；
- `comment` 给出档位参考（A/B/C 或 Excellent/Very good/Good/OK）与两条具体建议；
- 严格按题目要求的要点数给分：漏一个要点扣一个要点，
  要点齐全但语言错误多不要判满分；
- 不要因为书写不工整而降低内容档位，单独在 `comment` 里提示。

## 订正惯例

学校惯例是在错处标注并要求下次作业前订正（部分学校用 "Correct" 标记）。
在 `comment` 里用中文写明"请在下次作业前订正"，不要凭空生成教师姓名或签名。

## Verification

- 拼写类是否逐字母比对（不能整体看"像不像"）；
- 语法错误是否指到了具体语法点（error_type），而非笼统说"语法错误"；
- 书面表达是否标了 `answer_type=open` 且四个维度都看过；
- 学生表达与参考答案不同时，是否确认了意思再判定（避免误判）。

## Escalate（转人工复核）

- 书面表达、开放性回答：标 `needs_review=true`，`review_reason` 写
  "主观表达需教师确认"；
- 手写体辨认困难（如 a/o、r/v 混写）导致拼写判断不确定 →
  `confidence=low` + `needs_review=true`，不要猜字母；
- 题目本身印刷不清（选项、音标缺失）→ `unreadable`。
