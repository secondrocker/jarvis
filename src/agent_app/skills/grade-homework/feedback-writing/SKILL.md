# 评语撰写规范（Glow-Grow-Go）

## 结构

- `glow`（亮点，1–3 条）：具体到题目里的真实细节。
  写"第 3 题你把 156 拆成 99+57，思路很清楚"，不写"你真棒""很聪明"；
- `grow`（改进，1–3 条）：一条一个点，说清**错在哪 + 正确思路是什么**，
  不重复诊断里的专业术语，换成学生能懂的话；
- `go`（下一步，必须恰好 1 条）：学生今天或明天就能做到的动作，
  如"今天用竖式重算 3 道两位数乘法，写完检查进位"；
- `parent_note`（可选）：给家长的一句具体配合事项，
  如"请提醒孩子订正后把单位补上"，不要写成对孩子的评价。

## 语气与用语

- 面向学生：第二人称、句子短、低年级用词浅白；
- 鼓励要基于事实，不空洞表扬；批评要针对做法，不评价智力或态度；
- 不使用"太粗心""不认真""你怎么又"这类指责性表达；
- 不套模板：不要写"希望今后继续努力""争取更大进步"这类放在任何作业上都成立的话；
- 面向小学生避免专业术语（"进位遗漏"要写成"算的时候忘记把进上来的一加上"）。

## 内容边界（合规）

- AI 评语只是**预批建议**：教师确认后才写给学生（教育部《教师生成式人工智能
  应用指引》要求教师审核，不得直接套用模板作为最终评语）；
- 只依据输入里真实存在的判定与诊断写，不补充你没看到的作业细节，
  不编造学生姓名、班级、分数；
- 作文等主观内容：给方向性和鼓励性反馈，不给"定论式"评价；
- 不提及其他学生、不做横向比较排名。

## 与 summary 的分工

- `summary`（主代理写，1–2 句）：对整份作业的整体印象 + 最需要注意的一点，
  面向学生或家长快速浏览；
- `feedback`（本技能）：结构化的亮点-改进-下一步，用于详细反馈页面或家长沟通。

## Verification

- 每条 glow 都能对应到具体题目或具体做法（不能是通用表扬）；
- 每条 grow 都说明了"怎么改"，而不只是"哪里错了"；
- `go` 恰好一条，且是今天/明天可执行的；
- 全文没有空话套话、没有指责性语言、没有编造信息；
- 低年级用词适合学生阅读水平。
