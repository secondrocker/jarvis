# 语文作业批改规范

## 字词类（抄写 / 默写 / 看拼音写词语 / 组词）

- **逐字比对**，一个字一个判定单位；错别字、多字、漏字都算错；
- 形近字与易错字重点核对：己/已/巳、未/末、日/目、土/士、拔/拨、辨/辩/辫；
- 拼音：声母、韵母、声调都要对，轻声与儿化按教材标注；
- `error_detail.correct_form` 写出正确写法，`reason` 写清"错在哪一笔/哪个字"；
- 好字、佳句的肯定写进 `comment`（如"这个字间架结构写得好"），语气简短具体。

## 阅读理解

- 按**要点**给分：题目要求几点就给几点分，缺一点扣一点，不因表述不同而扣分；
- 学生用自己的话答对要点算正确；只答现象没答原因算 `partial`；
- `error_detail.correct_form` 给出参考答案或要点清单；
- 开放性问题（"你从中体会到什么"）只要言之有理即算正确，标 `answer_type=open`。

## 修改病句 / 句式转换

- 必须**改在病处**且不改变原意；只改一处而病句有两处病因算 `partial`；
- 用标准修改符号（删除号、调换号、增添号、修改号）判断是否符合要求；
- 改变了原意的"改对"算错误，`error_type` 记 `method`。

## 作文 / 看图写话（按档评等级，不给硬分数）

四个维度分别看，写进 `comment` 与 `error_detail.reason`：

1. **内容**：是否切题、中心是否明确、材料是否具体；
2. **语言**：用词准确、句子通顺、修辞与好词好句；
3. **结构**：条理清楚、分段合理、有开头结尾；
4. **书写卷面**：字迹工整、格式正确（标题、标点、分段）。

- `answer_type` 一律标 `open`，`verdict` 用 `partial` 或 `correct` 表达档位倾向，
  并在 `comment` 里给出**等第参考**（一类文/二类文，或优/良/合格），不要给数值分数；
- 作文必须有**总批**：先肯定具体优点，再指出一两处可改之处，
  最后给一条最值得做的改进；不要只写"语句通顺，继续努力"这类套话；
- 错别字、标点、字数、标题缺失单独列出（这些是可客观判定的部分）；
- 书写不工整时提示"建议重写/面批"，不要直接判整篇不合格。

## Verification

- 字词类是否逐字比对（不能整行只看一眼）；
- 错题是否都给出 `correct_form`；
- 阅读理解是否按要点计数给分，而非整体印象；
- 作文是否标了 `answer_type=open` 且给出总批与等第参考；
- 是否避免了对作文给出"最终分数"式结论。

## Escalate（转人工复核）

- 作文、开放性表达、说理类题目：全部标 `needs_review=true`，
  `review_reason` 写"主观表达需教师确认"（AI 不得直接作为最终评价）；
- 学生答案与参考答案表述差异大但语义可能成立时，不硬判错，标 `confidence=low`；
- 字迹潦草、涂改遮挡导致无法辨认 → `unreadable` + `needs_review=true`。
