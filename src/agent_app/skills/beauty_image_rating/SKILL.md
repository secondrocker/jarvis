# 女性人物图片评分与标签 Skill

## 1. 任务目标

分析输入图片中的女性主体，完成：

1. 图片内容标签提取；
2. 主体占画面比例估算；
3. 构图和图片质量评价；
4. 根据预设个人偏好计算偏好分；
5. 输出客观分、偏好分和最终综合分；
6. 标记需要人工复核的图片。

本 Skill 只评价图片呈现效果和标签匹配程度，不评价人物现实中的价值、身份或人格。

---

## 2. 输入

输入可以包含一张或多张图片。

每张图片应附带稳定的图片 ID：

```json
{
  "image_id": "000001",
  "image": "<image input>"
}
```

如一次输入多张图片，必须逐张独立分析，不得把不同图片的特征相互混淆。

---

## 3. 分析原则

### 3.1 只根据可见证据判断

不得凭空推测：

* 身份；
* 职业；
* 民族；
* 国籍；
* 性格；
* 健康状况；
* 人物是否经过整形。

例如，图片呈现职业装时只能标记为：

```text
OL风
职业装
通勤风
```

不得断言人物真实职业是办公室职员。

### 3.2 标签和评分分离

标签描述“图片里有什么”。

评分描述“这张图片与预设偏好的匹配程度”。

不得因为图片匹配个人偏好，就故意遗漏负面质量标签。

### 3.3 允许不确定

无法确认时使用：

* `unknown`
* `uncertain`
* 较低的 `confidence`

不得为了填满标签而猜测。

# 4. 标签体系

每个分类可以输出多个标签。

## 4.1 人物数量

允许标签：

* `单人`
* `双人`
* `多人`
* `局部人物`
* `无人`

个人偏好评分默认只针对主要人物。

多人图片中，主要人物定义为：

1. 画面面积最大的人物；
2. 位于视觉中心的人物；
3. 清晰度最高的人物；
4. 无法确定主次时标记 `primary_subject_uncertain`。

---

## 4.2 构图范围

允许标签：

* `脸部特写`
* `上半身`
* `半身`
* `大半身`
* `全身`
* `腿部为主`
* `腿部特写`
* `背影`
* `侧身`
* `坐姿`
* `站姿`
* `躺姿`
* `自拍`
* `镜面自拍`
* `低机位`
* `高机位`
* `正面构图`
* `侧面构图`

### 腿部特写定义

满足以下多数特征时标记：

* 腿部是画面的主要视觉主体；
* 腿部占人物可见区域的 60% 以上；
* 脸部可能不可见；
* 画面重点明确落在腿部线条、服饰或姿势；
* 不依赖强拉伸畸变制造视觉长度。

---

## 4.3 人物占画面比例

输出：

```json
{
  "subject_ratio": 0.76,
  "subject_ratio_confidence": 0.86
}
```

`subject_ratio` 是主要人物可见区域占整张图片面积的估算值，范围为 `0.00～1.00`。

该值不要求达到像素级准确，只需要落在合理区间。

对于腿部特写图片，将“主要腿部区域”作为主体范围计算，而不是要求完整身体出现。

允许区间标签：

* `主体过小`：小于 30%
* `主体偏小`：30%～50%
* `主体适中`：50%～65%
* `主体占比优秀`：65%～82%
* `主体偏满`：82%～92%
* `主体过满`：高于 92%

最佳区间约为：

```text
70%～80%
```

但以下情况可以例外：

* 腿部特写；
* 脸部特写；
* 有意留白的摄影构图；
* 环境人像。

* `腿部完整可见`
* `腿部为视觉重点`
* `腿部特写`
* `修长腿型`
* `匀称腿型`
* `结实腿型`
* `纤细腿型`
* `丰满腿型`
* `自然比例`
* `视觉拉伸`
* `疑似广角畸变`
* `疑似后期拉长`
* `腿部遮挡`
* `腿部姿态自然`
* `腿部姿态僵硬`

### 长腿判断规则

标记 `修长腿型` 时，应综合判断：

* 腿部相对躯干比例；
* 大腿、小腿比例；
* 腿部线条连续性；
* 拍摄角度；
* 透视关系；
* 是否存在明显广角畸变；
* 背景直线是否同时发生拉伸；
* 身体其他部分是否出现不自然缩放。

不得仅因为图片被纵向拉长，就标记为高质量长腿。

偏好优先级为：

```text
自然匀称修长
>
自然结实修长
>
自然纤细修长
>
普通匀称
>
单纯偏瘦
>
明显视觉拉伸
```

# 5. 评分系统

输出三个分数：

```text
quality_score
preference_score
final_score
```

范围均为 `0～100`。

## 5.1 客观质量分 quality_score

客观质量分不考虑个人偏好。

总分 100 分：

| 维度       | 最高分 |
| -------- | --: |
| 主体占比和构图  |  35 |
| 清晰度和画质   |  20 |
| 光线与色彩    |  15 |
| 姿势和线条自然度 |  15 |
| 背景与视觉干扰  |  10 |
| 裁切完整性    |   5 |

---

## 5.2 主体占比和构图评分

最高 35 分。

### 基础占比得分

| 主体占比     | 基础分 |
| -------- | --: |
| 0%～20%   |   5 |
| 20%～35%  |  12 |
| 35%～50%  |  20 |
| 50%～65%  |  28 |
| 65%～70%  |  32 |
| 70%～80%  |  35 |
| 80%～88%  |  30 |
| 88%～95%  |  23 |
| 95%～100% |  15 |

### 构图修正

可以在基础分上进行修正，但最终不超过 35 分。

加分：

* 腿部特写且主题明确：`+3`
* 有意留白且构图平衡：`+2`
* 人物位置符合视觉重心：`+2`

扣分：

* 无意义大面积空白：`-3`
* 关键身体部位被意外截断：`-3`
* 主体贴边严重：`-2`
* 背景抢夺视觉中心：`-2`
* 构图明显歪斜：`-2`

腿部特写图片不因缺少头部或上半身自动扣分。

# 6. 最终综合分

默认计算公式：

```text
final_score =
    quality_score × 0.40
  + preference_score × 0.60
```

结果四舍五入为整数。

示例：

```text
quality_score = 82
preference_score = 91

final_score = 82 × 0.40 + 91 × 0.60
            = 87.4
            = 87
```

个人偏好权重大于客观质量，但图片质量仍然会明显影响最终排名。

---

## 6.1 额外扣分

以下扣分直接作用于 `final_score`：

| 问题         |  扣分 |
| ---------- | --: |
| 明显模糊       |  -8 |
| 极低分辨率      |  -6 |
| 严重过曝或欠曝    |  -5 |
| 明显拉伸变形     | -10 |
| 疑似过度后期拉长腿部 |  -8 |
| 主体严重遮挡     |  -5 |
| 水印覆盖主体     |  -4 |
| 多人且主次不明    |  -4 |
| 图片重复或近似重复  |  -2 |

最低不得低于 0 分。

# 7. 评分等级

| 最终分数   | 等级 | 含义          |
| ------ | -- | ----------- |
| 90～100 | S  | 非常匹配偏好，优先收藏 |
| 80～89  | A  | 高度匹配        |
| 70～79  | B  | 明显匹配        |
| 60～69  | C  | 一般匹配        |
| 40～59  | D  | 偏好较弱        |
| 0～39   | E  | 不匹配或质量较差    |

# 8. 置信度

每张图片输出整体置信度：

```text
confidence: 0.00～1.00
```

建议范围：

* 图片清晰、单人、无遮挡：`0.85～0.98`
* 部分遮挡或低分辨率：`0.65～0.84`
* 多人、角度特殊或滤镜较重：`0.50～0.70`
* 丝袜材质或身材无法确认：低于 `0.60`

不得因为模型必须输出结果而人为提高置信度。

# 10. 输出一致性要求

1. 所有分项分数必须符合各自最高分；
2. `quality_score` 必须等于客观质量分项总和；
3. `preference_score` 必须等于偏好分项总和；
4. `final_score` 必须符合综合分公式和扣分规则；
5. `rating_level` 必须与最终分对应；
6. 标签必须来自本 Skill 定义的标签集合；
7. 不得同时输出相互矛盾的标签，例如：

   * `腿部不可见` 和 `腿部完整可见`
   * `主体过小` 和 `主体占比优秀`
   * `自然比例` 和 `比例严重失真`
8. 不得将普通紧身裤误标为黑丝；
9. 不得将过膝袜误标为连裤袜；
10. 不得把拍摄透视造成的视觉长度直接认定为自然长腿。

---

# 11. 特殊情况

## 11.1 只拍腿部的图片

允许获得最高腿部偏好分。

判断重点：

* 腿部是否完整或构图有意；
* 腿型是否自然；
* 是否存在拉伸；
* 腿部服饰是否清晰；
* 主体是否占据合理画面范围；
* 背景是否干扰。

不因脸部不可见而扣分。

输出标签：

```text
局部人物
腿部特写
腿部为视觉重点
```

---

## 11.2 纵向拉伸图片

如发现以下特征，应降低长腿评分：

* 人物和背景同时被纵向拉长；
* 门框、家具等比例异常；
* 脚部异常巨大或细长；
* 小腿和大腿比例不自然；
* 腰部、手臂或脸部同时变形；
* 图片宽高比异常；
* 线条出现明显液化痕迹。

输出：

```text
视觉拉伸
疑似后期拉长
```

并扣除相应分数。

---

## 11.3 多人图片

分别分析主要人物和次要人物，但只根据主要人物计算总分。

输出：

```json
{
  "primary_subject_index": 0,
  "secondary_subject_count": 1
}
```

无法确定主要人物时：

```json
{
  "manual_review": true,
  "review_reason": "primary_subject_uncertain"
}
```

---

## 11.4 动漫、绘画和 AI 图片

增加媒体类型标签：

* `真人照片`
* `AI生成图`
* `动漫`
* `插画`
* `三维渲染`
* `媒体类型不确定`

默认情况下，真人图片与非真人图片分开排序。

---

# 12. 简短执行指令

执行图片分析时，遵循以下顺序：

1. 判断媒体类型；
2. 找到主要人物；
3. 估算人物占比；
4. 提取客观标签；
5. 判断腿部是否为视觉重点；
6. 检查长腿是否源于自然比例或图片拉伸；
7. 计算客观质量分；
8. 计算个人偏好分；
9. 应用扣分；
10. 生成最终分和等级；
11. 校验 JSON 和分数一致性；
12. 只输出 JSON。
