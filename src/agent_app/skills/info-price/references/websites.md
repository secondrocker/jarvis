# 信息价网站清单

数据源按权威性排序：官方造价站 → 期刊汇编站 → 综合比价站。
站点改版或不可达时按降级顺序切换。

| 站点 | 类型 | 覆盖范围 | 适用场景 | 备注 |
|---|---|---|---|---|

## 查询策略

1. **优先官方**：目标省份有官方造价站时先查官方，作为基准价。
2. **期刊翻查**：需要历史多期数据（趋势分析）时用 zaojiaku/costku 按期翻查。
3. **交叉验证**：比价或关键决策数据用 gldjc 复核；冲突时并列呈现。
4. **降级顺序**：官方站不可达 → 期刊汇编站 → 综合比价站；全部失败时
   如实报告"渠道不可用"，不输出无来源价格。

## 抓取注意事项

- 期刊表格较宽，web_fetch 的 max_chars 建议 30000-40000，截断时重抓。
- 部分站点搜索需要选择省市区县与期次后才能出结果，检索关键词带上
  这些限定（如 `广东 2026年7月 信息价 螺纹钢 HRB400`）。
- 登录才能看的报价（gldjc 部分页面）跳过，改用其他来源。
